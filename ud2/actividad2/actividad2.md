## 1. Sistemas Operativos compatibles
Visual Studio Code es multiplataforma y admite arquitecturas x64 y ARM64 (el soporte directo para Windows de 32 bits y macOS Big Sur o inferior ha sido descontinuado en las versiones más recientes):
- Windows: Windows 10 y Windows 11 (ediciones de 64 bits).
- MacOS: Versiones compatibles con actualizaciones de seguridad de Apple (por lo general, la versión actual de macOS y las dos anteriores).
- Linux: Distribuciones basadas en glibc 2.28 o posterior y GLIBCXX 3.4.25 o posterior. Entre ellas:

## 2. Requisitos mínimos de hardware
- Procesador  
Requisito minimo oficial: 1.6 GHz o mas rápido (un solo nucleo)    
Recomendado para un uso fluido: multi-nucleo a 2.0 GHz+

- Memoria RAM   
Requisito minimo oficial: 1 GB de RAM  
Recomendado para un uso fluido: 4 GB a 8 GB o superior (ampliable según extensiones)

- Almacenamiento  
Requisito minimo oficial: Disco duro de al menos < 500 MB libres  
Recomendado para un uso fluido: Unidad SSD con espacio disponible para proyectos y cachés

- Descarga  
Requisito minimo oficial: ~200 MB de instalador  
Recomendado para un uso fluido: Conexión a Internet para la instalación de extensiones

## 3. Versiones y canales de distribución disponibles
- Canal Estable (Stable Build)  
Es la versión oficial de producción recomendada para uso diario.

- Canal Insiders (Insiders Build)  
Versión en desarrollo con las últimas características recién implementadas.

- Formatos de distribución según la plataforma  
Windows: Instalador de usuario (User Installer), Instalador de sistema (System Installer) y archivo comprimido ejecutable sin instalación (Portable / .zip).  
macOS: Aplicación en formato .app comprimido en .zip (Universal, Intel y Apple Silicon).  
Linux: Archivos .deb (Debian/Ubuntu), .rpm (Fedora/RHEL/SUSE), paquetes Snap, Flatpak y comprimidos .tar.gz.  

- VS Code for the Web  
Versión que se ejecuta directamente desde el navegador web sin necesidad de instalación local.

## 4. Evaluación de compatibilidad con un equipo específico
- Sistema Operativo y versión: (Ejemplo: Windows 10 de 64 bits, Ubuntu 22.04, macOS Monterey...)

- Arquitectura: (32 bits vs 64 bits / x86 vs ARM)  

- Memoria RAM: (Ejemplo: 2 GB, 4 GB, 8 GB...)  

- Procesador: (Modelo o velocidad en GHz)
