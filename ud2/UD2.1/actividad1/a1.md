¿Puede funcionar un ordenador sin un sistema operativo instalado? Justifica tu respuesta.  

No, un ordenador no puede funcionar de forma completa ni útil sin un sistema operativo (SO) instalado, aunque sí es capaz de encender y realizar comprobaciones de hardware básicas.

¿Por qué un programa necesita hardware para ejecutarse?

Un programa necesita hardware porque este proporciona la infraestructura material y la energía necesarias para ejecutar esas instrucciones y convertirlas en acciones reales.

¿Qué diferencia existe entre un sistema operativo y una aplicación?

La diferencia fundamental entre un sistema operativo (SO) y una aplicación radica en su propósito y en el nivel en el que operan dentro del ordenador. Mientras que el sistema operativo es el encargado de gestionar la máquina, la aplicación está diseñada para que tú, como usuario, realices una tarea específica.

¿Qué papel desempeñan los recursos humanos dentro de un sistema informático?

Dentro de un sistema informático, los recursos humanos desempeñan el papel más crítico e indispensable: son el conjunto de personas que diseñan, alimentan, operan, mantienen y utilizan tanto el hardware como el software.

## 2. Capas de un sistema informático

Dispositivos fisicos: Los componentes de hardware que participan en el proceso, destacando el disco SSD donde finalmente se guarda el archivo PDF, la memoria RAM, la CPU y los controladores de red.  

Microarquitectura: La organización interna y circuitería del procesador (CPU), como la unidad aritmético-lógica (ALU) y los registros, que ejecutan físicamente las instrucciones de bajo nivel.

Lenguaje de maquina: Las instrucciones en código binario (ceros y unos) específicas del procesador que traducen las operaciones lógicas necesarias para procesar la descarga y la escritura de datos.

Sistema Operativo: El sistema Ubuntu (incluyendo su núcleo o kernel), encargado de administrar la red para descargar el archivo, gestionar la memoria RAM y controlar el acceso al almacenamiento.

Programas de sistema: Las utilidades, bibliotecas y servicios del entorno gráfico de Ubuntu que facilitan la ejecución de Firefox y la gestión visual de la sesión.

Programas de usuario: El navegador web Firefox, que el usuario abre para acceder a la página web y solicitar la descarga del archivo PDF.

¿Qué funciones desempeña Firefox durante la descarga?

En el escenario planteado, Firefox (como programa de usuario o aplicación) desempeña las siguientes funciones clave durante la descarga del archivo PDF: Peticion de recursos, recepcion de datos, gestion de la interfaz visual y solicitud de almacenamiento

¿Qué operaciones realiza el sistema operativo para guardar el archivo?

En el contexto del escenario planteado, el sistema operativo (Ubuntu) realiza una serie de operaciones a nivel de software y gestión de recursos para completar el almacenamiento: Recepcion de la solicitud, gestion del sistema de archivos, uso de la memoria, interaccion con los controladores y confirmacion de finalizacion.

¿Por qué Firefox no necesita conocer el funcionamiento electrónico del SSD?

Firefox no necesita conocer el funcionamiento electrónico del SSD gracias al principio de abstracción y a la arquitectura en capas del sistema informático.

¿Qué ventajas proporciona esta organización por capas a los desarrolladores de aplicaciones?

La organización en capas proporciona enormes ventajas a los desarrolladores de software, permitiéndoles crear aplicaciones potentes y eficientes sin necesidad de conocer ni programar para los detalles físicos de la máquina.

¿Qué diferencia existe entre un dato fijo y uno variable?

Dato fijo (o constante): Es aquel valor que no cambia a lo largo de la ejecución de un programa o del ciclo de vida de un proceso informático. Permanece inmutable.

Dato variable: Es aquel valor que sí puede modificarse o cambiar de valor durante la ejecución del programa según las acciones del usuario, los cálculos internos o los datos recibidos.

Indica un ejemplo de dato fijo y otro variable en una aplicación informática

Ejemplo de dato fijo: El valor del número Pi (pi = 3,1416) o la dirección de correo oficial del soporte técnico en la pantalla de ayuda de un sistema.

Ejemplo de dato variable: El saldo en la cuenta bancaria del usuario dentro de una app de banca o la puntuación de un jugador dentro de un videojuego.

## 4. Tratamiento de la información

### A. Busqueda de archivos

Entrada: El usuario introduce el nombre del archivo en el buscador del sistema operativo.

Procesamiento: El sistema busca y compara el criterio de búsqueda con los archivos existentes

Salida: El sistema muestra los archivos coincidentes en pantalla.

Almacenamiento: No se realiza almacenamiento permanente adicional, ya que solo se consultan los archivos ya guardados en el sistema

### B. Camara digital

Entrada: El usuario toma la fotografía con el teléfono móvil

Procesamiento: El dispositivo procesa la señal del sensor para generar la imagen digital de la fotografía.

Salida: El usuario visualiza la fotografía en la pantalla del teléfono móvil.

Almacenamiento: El teléfono guarda la fotografía en la memoria interna o tarjeta de almacenamiento.

### C. Navegador Web

Entrada: El usuario introduce una dirección web.   

Procesamiento: El navegador solicita la página y procesa los datos recibidos de la red

Salida: El navegador muestra el contenido de la página web.

Almacenamiento: No se realiza almacenamiento permanente (salvo la caché temporal de navegación, no especificada como guardado permanente)

Qué diferencia existe entre procesar información y almacenarla?

Procesar información: Consiste en manipular, calcular, transformar, buscar o analizar los datos de entrada para convertirlos en un resultado útil o nueva información.

Almacenar información: Consiste en guardar, retener o registrar los datos de manera persistente en un soporte físico (como un disco duro, SSD o memoria flash) para poder recuperarlos en el futuro.

¿Puede un sistema informático realizar operaciones de procesamiento sin mostrar inmediatamente los resultados al usuario? Pon un ejemplo.

Sí, los ordenadores y dispositivos realizan constantemente tareas de procesamiento en segundo plano sin que el usuario vea un resultado directo en la pantalla de forma inmediata.

Ejemplo: Un programa antivirus que analiza en segundo plano todos los archivos del disco duro en busca de amenazas mientras el usuario navega por internet o trabaja en otra aplicación, guardando el registro de forma interna o avisando únicamente si encuentra un peligro.

### Apartado C. Analisis

¿Cuántos píxeles tiene la imagen?

La imagen tiene 16 píxeles (resultado de multiplicar 4 filas por 4 columnas).

¿Cuántos bits se necesitan para representarla?

Se necesitan 16 bits, ya que cada uno de los 16 píxeles utiliza exactamente 1 bit.

¿Cuántos bytes ocupa la representación de los píxeles, sin contar información adicional?

Ocupa 2 bytes, ya que $1\text{ byte} = 8\text{ bits}$ y $\frac{16\text{ bits}}{8\text{ bits/byte}} = 2\text{ bytes}$. 

¿Cuántas imágenes diferentes pueden representarse con 16 píxeles si cada uno puede ser blanco o negro?

Como cada píxel solo tiene 2 estados posibles (blanco o negro), la cantidad de combinaciones posibles es de $2^{16}$, lo que da un total de 65.536 imágenes diferentes. 

¿Qué limitaciones tendría este sistema para representar fotografías reales?

Falta de color y tonos intermedios: Al usar solo 1 bit por píxel (0 o 1), únicamente se pueden representar el blanco y el negro puros, sin escalas de grises ni colores.   

Resolución extremadamente baja: Una rejilla de 4 x 4 píxeles solo ofrece 16 puntos de detalle, por lo que las formas complejas, curvas o bordes de una fotografía real se verían irreconocibles o pixelados. 

## 6. Investigación sobre el acceso a archivos

### Apartado A. Investigación de conceptos

Biblioteca de software - 

Qué es: Conjunto de código o funciones predefinidas que las aplicaciones utilizan para no reinventar operaciones comunes.

Función: Visual Studio Code invoca funciones estándar de lectura de archivos de una biblioteca de software (como fs.readFile en Node.js/Electron) para solicitar el archivo main.js.

Llamada al sistema (system call) - 

Qué es: Mecanismo o interfaz que permite a un programa de usuario solicitar un servicio al núcleo del sistema operativo.

Función: La biblioteca convierte la petición de Visual Studio Code en una llamada al sistema (como open o read) para pedirle a Ubuntu/SO el acceso al archivo main.js.

Núcleo del sistema operativo (kernel) - 

Qué es: La parte central del sistema operativo que gestiona de manera segura los recursos del sistema y el hardware

Función: Recibe la llamada al sistema, verifica las licencias y permisos de acceso al archivo main.js y coordina su búsqueda y lectura.   

Sistema de archivos - 

Qué es: La estructura lógica que organiza, nombra y administra cómo se almacenan los datos en el disco (ej. ext4, NTFS).

Función: Traduce la ruta del archivo main.js a la dirección física o bloques de datos del disco donde se encuentra guardado.

Controlador de dispositivo (driver) - 

Qué es: Software intermedio que permite al sistema operativo comunicarse directamente con un componente de hardware específico.   

Función: El kernel envía las instrucciones de lectura al driver del SSD, convirtiendo las órdenes lógicas en comandos de entrada/salida que el disco entiende.

Caché de páginas (page cache) - 

Qué es: Área de la memoria RAM administrada por el kernel que guarda temporalmente páginas de datos leídas del disco.   

Función: Si main.js ya fue leído recientemente, el kernel lo entrega directamente desde la RAM sin necesidad de acceder de nuevo al disco físico.   

Controlador electrónico del SSD - 

Qué es: El chip procesador integrado en el interior del propio disco SSD que gestiona su funcionamiento físico.

Función: Recibe las órdenes del driver, localiza las celdas de memoria exactas y gestiona la lectura electrónica de los datos de main.js.

Memoria flash - 

Qué es: El medio de almacenamiento no volátil compuesto por celdas de transistores donde se guardan los datos físicamente.

Función: Guarda los bits retenidos electrónicamente que componen el código fuente del archivo main.js para ser transferidos a la RAM.

### Apartado B. Aplicaciones y sistema operativo

¿Qué diferencia existe entre una función de una biblioteca de software y una llamada al sistema?

Una biblioteca de software ofrece rutinas de alto nivel en el espacio de usuario para facilitar tareas cotidianas. En cambio, la llamada al sistema (system call) es el mecanismo formal y protegido mediante el cual el programa solicita servicios directamente al núcleo del sistema operativo.

¿Qué función desempeña el núcleo del sistema operativo durante la lectura de un archivo?

El núcleo recibe la petición, verifica los permisos de seguridad de la aplicación, interpreta la estructura del sistema de archivos y coordina la recuperación y transferencia de los datos.

¿Por qué una aplicación no accede normalmente de forma directa al hardware del SSD?

Por motivos de seguridad y estabilidad del sistema, evitando que un error de programación en una aplicación pueda corromper de forma directa todo el almacenamiento físico.

¿Qué ventajas tiene para los desarrolladores utilizar las interfaces proporcionadas por el sistema operativo?

Permite la abstracción del hardware, simplifica la escritura del código al no depender de componentes físicos específicos y garantiza la portabilidad de las aplicaciones.

### Apartado C. Memoria y almacenamiento

¿Cómo localiza el sistema operativo los datos de un archivo a partir de su nombre y ruta?

Utiliza el sistema de archivos para consultar las estructuras de metadatos y directorios, traduciendo la ruta lógica en las direcciones y bloques físicos exactos del disco.

¿Qué es la caché de páginas y para qué se utiliza?

Es un área de la memoria RAM administrada por el núcleo que retiene temporalmente datos leídos recientemente para acelerar el acceso y evitar lecturas innecesarias al disco físico.

¿Qué ocurre si el contenido del archivo ya se encuentra en la caché de páginas?

Se produce un acierto de caché y el sistema operativo entrega el contenido de forma inmediata directamente desde la memoria RAM, reduciendo el tiempo de espera.

¿Qué ocurre si es necesario recuperar los datos físicamente del SSD?

Se genera un fallo de caché, lo que obliga al sistema a solicitar la lectura de los datos al dispositivo de almacenamiento para cargarlos en la memoria.

¿Qué diferencia existe entre el controlador de dispositivo del sistema operativo y el controlador electrónico del SSD?

El controlador de dispositivo es un software que opera dentro del sistema operativo para traducir las órdenes del núcleo, mientras que el controlador electrónico del SSD es un circuito o microchip físico integrado en el propio disco encargado de gestionar la memoria flash internamente.
