## 2. Crear el repositorio

Primero, vamos a situarnos en la raiz que queramos que tenga el repositorio Git, en este caso sera yoesansan-sistemas/docs.

Ahora vamos a inicializar Git con el comando git init

![](./imagenesA5/Captura%20de%20pantalla%20-2026-10-19%2016-21-31.png)

Una vez inicializado el repositorio vamos a comprobar que todo esta en orden y para identificar la rama, con el comando git status

![](./imagenesA5/Captura%20de%20pantalla%20-2026-10-19%2016-23-23.png)

## 3. Primer commit

Para hacer nuestro primer commit lo que tenemos que hacer antes de todo es añadir todo lo que hemos editado con el comando git add . para que nos añada todo directamente

![](./imagenesA5/Captura%20de%20pantalla%20-2026-10-19%2016-25-24.png)

Una vez añadido todos los cambios volvemos a poner el comando git status para ver todo lo que se ha guardado

![](./imagenesA5/Captura%20de%20pantalla%20-2026-10-19%2016-26-03.png)

Una vez hecho todo esto, ahora si, hacemos el commit con el siguiente comando: git commit -m " "

![](./imagenesA5/Captura%20de%20pantalla%20-2026-10-19%2016-27-18.png)

Por ultimo vamos a consultar el historial de commits para comprobar que hemos hecho el commit bien

![](./imagenesA5/Captura%20de%20pantalla%20-2026-10-19%2016-28-39.png)

## 4. Registrar cambios

Para este ejercicio vamos a modificar los cambios del index.md dentro de la carpeta de docs

Una vez hecho esto vamos a: 

### Comprueba el estado del repositorio.

![](./imagenesA5/Captura%20de%20pantalla%20-2026-10-19%2016-32-14.png)

Vemos que se han actualizado los cambios que hemos hecho

### Consulta las diferencias respecto al último commit.

![](./imagenesA5/Captura%20de%20pantalla%20-2026-10-19%2016-33-08.png)

Con el comando git diff vemos los cambios que habia en el documento con respecto al commit anterior

### Prepara el archivo modificado.

![](./imagenesA5/Captura%20de%20pantalla%20-2026-10-19%2016-34-27.png)

Con el comando git add volvemos a guardar todos los cambios. En este caso como sabemos que solo hay un cambio en el documento que tenemos localizado podemos ponerlo directamente

### Crea un nuevo commit.

![](./imagenesA5/Captura%20de%20pantalla%20-2026-10-19%2016-35-49.png)

Con el mismo comando anterior ya hecho todo lo que hemos hecho podemos hacer un segundo commit

### Consulta nuevamente el historial.

![](./imagenesA5/Captura%20de%20pantalla%20-2026-10-19%2016-36-37.png)

Por ultimo vemos el historial de commits con el comando git log y vemos que estan los dos commits

## Estos son todos los comandos utilizados en esta actividad

git init
git status
git add .
git commit -m " "
git log
git diff
