![](./img7/Captura%20de%20pantalla%20-2026-10-21%2019-28-45.png)

![](./img7/Captura%20de%20pantalla%20-2026-10-21%2019-30-41.png)

Despues de todo esto tenemos que hacer todo lo practicado en las anteriores actividades. Hacemos git add y git commit para actaulizar todos los cambios

![](./img7/Captura%20de%20pantalla%20-2026-10-21%2019-34-30.png)

Y hacemos el push al repositorio de GitHub

![](./img7/Captura%20de%20pantalla%20-2026-10-21%2019-36-16.png)

## 2. Publicar con GitHub Pages

Vamos a seguri los siguientes pasos para acceder al GitHub Pages

Una vez en nuestro repositorio de GitHub nos vamos a la pestaña de Settings

![](./img7/Captura%20de%20pantalla%20-2026-10-21%2019-37-45.png)

Luego dentro de Settings le damos a Pages

![](./img7/Captura%20de%20pantalla%20-2026-10-21%2019-38-28.png)

Dentro de Pages en Build and deployment le damos a Deploy from a branch

![](./img7/Captura%20de%20pantalla%20-2026-10-21%2019-39-18.png)

Ponemos la rama main y el directorio /

![](./img7/Captura%20de%20pantalla%20-2026-10-21%2019-40-54.png)

Y ya por ultimo vemos como ya esta en proceso de subirse

![](./img7/Captura%20de%20pantalla%20-2026-10-21%2019-52-02.png)
