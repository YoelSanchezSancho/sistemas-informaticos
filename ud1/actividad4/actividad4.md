Para crear los encabezados en Markdown hay que usar la combinacion de teclas "AltGr" y el numero "3" para poner "#" que es el elemento encargado de crear los encabezados.

Hay un orden jerarquico de mayor a menor segun el numero de "#" que hayas puesto. Aqui va una demostración visual.

## 5. Listas
Hay diferentes tipos de listas: ordenadas, desordenadas, de tareas y anidadas.

### Lista no ordenada
Para hacer una lista no ordenada solo basta con poner un "-" ha cada elemento. Ejemplo:

![](./imagenes/Captura%20de%20pantalla%20-2026-09-24%2020-27-55.png)

### Lista ordenada
Para hacer una lista ordenada solo basta con poner el numero por orden seguido de un "." ha cada elemento. Ejemplo:

![](./imagenes/Captura%20de%20pantalla%20-2026-09-24%2020-29-31.png)

### Lista de tareas
Para hacer una lista de tareas solo basta con poner un "-" y luego poner "[x]" si la tarea esta completada o "[ ]" si la tarea esta sin completar. Ejemplo:

![](./imagenes/Captura%20de%20pantalla%20-2026-09-24%2020-31-49.png)
